Prism Launcher updates itself

Everything set up in one go, and kept matching the server: when its mods change, yours update the next time you press Play.

  1. Install Prism Launcher (free, for Windows, Mac and Linux) and sign in with your Microsoft account.
  2. Download the instance below and drag the file into Prism's window (or Add Instance → Import).
  3. Press Play. The first start downloads the mods, which takes a few minutes. The server is already in your multiplayer list.
