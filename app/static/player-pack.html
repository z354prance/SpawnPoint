Play with the SpawnPoint app

It sets everything up and keeps your mods matching the server's. You only do this once.

  1. Get the app
    Download the app
  2. Add this server to it
    Add to the SpawnPoint app
    Nothing happened? Install the app from step 1 first, then press this again.
  3. Press Play The first time, the app downloads the mods. After that it only fetches what changed, and joins the server for you.

Other ways to join

Prism Launcher

An instance that updates its mods every time you press Play (slower than the app).

Download
How to use it
  1. Install Prism Launcher and sign in with your Microsoft account.
  2. Drag the downloaded file into Prism's window (or Add Instance → Import).
  3. Press Play. The server is already in your multiplayer list.
Modrinth App

One file with everything. Download it again when the server's mods change.

Download
How to use it
  1. Install the Modrinth App and sign in.
  2. Open the downloaded file with it, or drag it onto the app's window.
  3. Press Play, then join from the multiplayer list.
